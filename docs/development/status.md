# 현재 범위와 다음 작업

기준: 2026-10-11. 코드에 없는 계획을 완료된 기능으로 취급하지 않는다.

| 영역 | 현재 구현 | 남은 작업·제약 |
|---|---|---|
| 로그인 | 로컬 DB 아이디·비밀번호, BCrypt, 서버 세션, CSRF, 계정 운영 명령 | 가입·비밀번호 찾기·MFA·로그인 시도 제한 없음 |
| 권한 엔진 | Membership·Role·Permission·ACL, 슈퍼유저, 감사, 정책 버전·잠금, 마지막 관리자 보호 | 명시적 DENY·상속 차단·파일별 ACL·권한 캐시 없음 |
| 권한 관리 화면 | 직원 등록·역할 배정·소속 종료, 역할과 권한 편집, 감사 기록 조회 | 계정 생성과 소속 등록이 한 트랜잭션이 아님. 권한 관리 권한끼리의 분리 없음 |
| 자료실 | 트리·이동·이름 변경·휴지통·복원·영구 삭제, 파일 전송, 작업 원장, 요청별 권한 강제와 목록 필터, 폴더 ACL 화면 | 저장소 어댑터는 로컬 파일시스템 하나. 원격 저장소 어댑터 없음 |
| 업무일지 | 업무 5종, 상담 전송, 날짜별 일일보고와 5단계 제출, 공지, 캘린더, 담당 반·태그 | 알림·리마인드 없음 |
| 외부 ERP 연동 | 포트 하나와 가상 데이터를 돌려주는 대역 어댑터 | 실제 연동 어댑터 없음. [연동 문서](../architecture/tng.md)의 "두지 않은 것" 참조 |
| 직원·학생 | 계정과 학원 소속만 있음 | 학생·반을 직접 소유하는 도메인 없음. 반과 학생은 외부 ERP의 자료를 읽음 |

## 운영에 올리기 전에 확인할 것

- 핵심 조회가 학원 단위 전체 로드다(자료실 트리, 업무 목록, 계정 이름). 수천 건 규모를 가정했고 그 이상은 재 보지 않았다.
- 거부 감사는 별도 트랜잭션으로 쓰므로 거부되는 요청 하나가 DB 연결 두 개를 잡는다. 연결 풀 크기는 기본값이다.
- 끊긴 자료실 작업의 재실행과 상담의 대조는 사람이 화면에서 실행한다. 주기적으로 도는 작업이 없다.

- 세션이 프로세스 메모리에 있어 재시작하면 다시 로그인한다. 인스턴스를 늘릴 수 없다.
- 업무일지의 첨부는 DB에 둔다(파일 하나에 4MB). 많아지면 자료실 저장소로 옮기는 편이 맞다.
- 일일보고의 제출 조건은 제출하는 순간 한 번 계산한다. 계산과 저장 사이에 바뀐 값은 반영되지 않는다.
- HTTPS, 접근망 제한, 백업·복구는 배포 환경에서 따로 구성한다.
