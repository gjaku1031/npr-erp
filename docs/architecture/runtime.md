# 실행 환경

## 구성

애플리케이션 한 프로세스와 PostgreSQL이 전부다. 화면도 같은 프로세스가 그린다.

| 상태 | 저장 위치 |
|---|---|
| 계정·권한·자료실 메타데이터·작업 원장·업무일지 | PostgreSQL |
| 업무일지 첨부(파일 하나에 4MB까지) | PostgreSQL |
| 자료실 파일 본문 | `npr.storage.local-root` 아래의 디스크 |
| 로그인 세션 | 프로세스 메모리 |
| 외부 ERP 대역이 받은 알림장·상담 | 프로세스 메모리(재시작하면 사라짐) |

Redis, 메시지 브로커, 분산 세션, 범용 Job 서버는 없다.

## 프로필

| 프로필 | 동작 |
|---|---|
| 없음 | 시연 데이터를 넣지 않음. 첫 계정은 운영 명령으로 만듦 |
| `local` | 빈 DB에 시연 데이터를 넣음 |
| `test` | 통합 테스트용. 파일은 `build/test-storage`에 둠 |

## 운영 제약

DB 접속 정보는 환경 변수로 넣는다. HTTPS에서는 `SESSION_COOKIE_SECURE=true`로 세션 쿠키에 Secure를 붙인다.
Forwarded 헤더는 신뢰할 수 있는 reverse proxy에서만 오도록 구성한다.

세션은 재시작하면 사라진다. 인스턴스를 늘려야 하면 공유 세션이나 다른 인증 모델을 새 ADR에서 정한다.
자료실 파일 디렉터리는 DB와 함께 백업해야 한다. 한쪽만 되돌리면 메타데이터와 본문이 어긋난다.
