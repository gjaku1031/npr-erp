# ADR-0009: 외부 ERP 연동을 포트 하나와 대역 어댑터로 둠

- 상태: **Accepted**
- 날짜: 2026-10-10

## 맥락

반·학생·출결·상담은 외부 ERP가 원장이다. 실제 연동 구현은 그 ERP의 화면과 요청을 따라가며 세션, 조회, 제한된
쓰기를 다루는데, 외부 ERP의 비공개 계약과 실제 계정에 묶여 있어 저장소에 둘 수 없고 계정 없이는 실행해 볼 수도 없다.

## 결정

연동을 `tng` 모듈의 인터페이스 `TngGateway` 하나로 두고, 구현은 가상 데이터를 결정적으로 만들어 돌려주는
`MockTngGateway`만 둔다. 실제 연동 구현, 계정, 계약 문서는 이 저장소에 두지 않는다.

- 포트가 주고받는 타입은 이 저장소가 정한다. 외부 ERP의 필드 구조를 밖으로 내보내지 않는다.
- 업무일지에는 연동 방식과 무관한 규칙만 둔다: 전송 상태와 대조, 빈 명단으로 지우지 않기.
- 실제 연동에만 필요한 장치(계정·세션, 선점 만료, 충돌 해소)는 두지 않는다. 목록은 [연동 문서](../architecture/tng.md)에 둔다.

## 결과

저장소만으로 전체 기능을 실행하고 테스트할 수 있다. 대역은 실패하지 않으므로 외부 장애와 지연에 대한 동작은
검증되지 않는다. 실제 어댑터를 붙일 때 두지 않은 장치를 설계해야 한다.
